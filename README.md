# character-network-visualization

Implement a program that:

1. Use a character dictionary to identify character names
2. Detect relationships between characters based on their co-occurrence within a context window (length 30) or scene
3. Visualize the character relationship network using GraphViz

## Data:

Macbeth.txt: Text from Project Gutenberg ([https://www.gutenberg.org](https://www.gutenberg.org/))

CharacterDict.txt: Dictionary containing character names in capitalized format
